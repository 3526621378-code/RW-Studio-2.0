## 收到 ICP 审核通过短信后

1. 保存完整的 ICP 备案号和审核通过日期。
2. 在阿里云 DNS 添加两条 A 记录：
   - `@` → `121.40.38.200`
   - `www` → `121.40.38.200`
3. 将备案号填入服务器 `/etc/rw-studio.env` 的 `ICP_NUMBER`。
4. 从 Gitee 国内镜像部署代码，启动 Next.js 与 Nginx。
5. 确认 HTTP 域名访问正常后申请 HTTPS 证书。
6. 验证主域名、www、全部页面、静态资源、移动端和备案链接。
